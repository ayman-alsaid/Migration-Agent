# Public Engineering Evidence Notice

The production source code for Migration Agent is maintained in a private repository and is not distributed publicly.

This public repository is maintained as an engineering portfolio and technical case study. It documents the system architecture, implemented capabilities, engineering decisions, interfaces, verification methodology, deployment model, evidence boundaries, and known limitations.

Its purpose is to give technical reviewers sufficient evidence to evaluate the engineering work while protecting proprietary implementation details, credentials, operational configuration, and sensitive domain logic.

Claims in this repository are deliberately separated into implemented, deployed, estimated, researched, and not-yet-validated categories. In particular, the broader domain adaptations described here are architectural research directions, not claims that those verticals have already been built.
